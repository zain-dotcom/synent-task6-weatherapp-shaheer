# Synent Technologies - Task 6: Weather App (API Integration)

A command-line weather application built with Python using the OpenWeatherMap REST API. Developed as part of the Python Development Internship Program at Synent Technologies.

## 📌 Features
- **Real-Time Data**: Queries live meteorological statistics for any global city.
- **Core Metrics**: Displays weather description, temperature (°C), "feels like" temp, humidity (%), and wind speed (m/s).
- **Robust Error Handling**: Gracefully handles non-existent cities (404), unauthorized requests (401), timeouts, and lack of network connectivity.

## 🛠 Tech Stack
- **Language**: Python 3.x
- **Libraries**: `requests`
- **API**: OpenWeatherMap Current Weather Data API

## 🚀 Getting Started

### Prerequisites
- Python 3.8+ installed.
- A free API key from [OpenWeatherMap](https://openweathermap.org/).
